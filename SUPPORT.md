# Getting help

SkillShield is maintained in limited time. This page shows where to go so your question reaches the right place.

## Where to ask

| You want to | Go to |
|---|---|
| Report something that is broken | [Issues](https://github.com/obielin/skillshield/issues/new/choose): **Bug report** |
| Report a safe skill that was flagged | [Issues](https://github.com/obielin/skillshield/issues/new/choose): **False positive** |
| Report a malicious skill that was not flagged | [Issues](https://github.com/obielin/skillshield/issues/new/choose): **Detection gap** |
| Propose a new rule | [Issues](https://github.com/obielin/skillshield/issues/new/choose): **New rule proposal** |
| Suggest a feature | [Issues](https://github.com/obielin/skillshield/issues/new/choose): **Feature request** |
| Ask how to do something | [Discussions](https://github.com/obielin/skillshield/discussions) |
| Report a vulnerability in SkillShield | Privately, as described in [SECURITY.md](SECURITY.md) |

## Before you open an issue

1. Search the existing issues, in case it has been reported.
2. Upgrade to the latest version: `pip install -U skillshield`.
3. Note your SkillShield version (`skillshield --version`), your Python version and your operating system.

## What issues are not for

- Asking whether a particular third-party skill is safe to install. Run the scan and read the findings, or ask in Discussions.
- Support for modified forks.
