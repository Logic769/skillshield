## Trust and access

SkillShield is security tooling that people run on their own machines and in CI, so access is granted carefully:

- **Generous with credit, careful with access.** Credit is public and frequent. Merge and release rights are earned.
- **Identity is confirmed** before anyone is given merge or release access.
- **Every change is reviewed**, including the lead maintainer's own, before it is released.

## Want to help maintain?

Start by contributing and reviewing other people's pull requests. If you would like to take on more, say so in an issue or a discussion.
